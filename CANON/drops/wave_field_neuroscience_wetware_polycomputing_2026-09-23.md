## 1. Distributed binding via ripple synchrony — [EST]

**Source:** Verzhbinsky, Halgren et al. [names corrected 2026-09-23 by Oryon/Discord session — the
video audio garbles these as "Veselovsky"/"Halpern"; Nature citation block reads "Verzhbinsky, I.A.,
Daume, J., Cheng, S. et al."], "Cross-region neuron co-firing mediated by ripple
oscillations supports distributed working memory representations," *Nature Neuroscience*,
2026 (s41593-026-02403-z). Verified against the actual abstract, not a secondhand summary.

Intracranial recordings (hippocampus, amygdala, vmPFC, ACC, pre-SMA, bilateral) during a working
memory task. ~90 Hz ripples increase cross-region co-firing ~30%, **no decrement out to 220mm**,
scale with memory load, and reinstate stimulus-specific long-distance firing patterns during
retrieval. This is a real, well-instrumented, human intracranial dataset — solid empirical ground
for "a thought is a distributed, momentarily-synchronized network state," not a localized event.

**EILT mapping [A, analogy — ours, not the paper's claim]:** matches the Ledger Commit concept —
distributed state brought into momentary coherence, written when phase-aligned, rather than stored
in one place.

## 4. Ephaptic coupling and the "analog brain" theory — [E] mechanism / [HYP] theory (corrected
tags — the original PDF marked the whole cluster [E], which overclaims)

**Mechanism, empirical [E]:** Pinotsis & Miller, MIT Picower Institute, *Cerebral Cortex*, July
2026. Intracranial LFP recordings during working memory tasks; Granger causality analysis shows
electric fields exert a **dominant, top-down influence** on neural spiking (ephaptic coupling),
trial-by-trial, not just as a spiking byproduct. Real, quantitative, published.

**Theory built on it, hypothesis [HYP]:** Miller, Brincat & Roy, "Analog Cognition and
Consciousness," *J Neurosci* 46(33):e0711262026, Aug 19 2026 — proposes that cognition and unified
consciousness emerge from bidirectional spiking<->wave interaction: alpha/beta waves as "mobile
stencils" routing which neural ensembles activate, enabling parallel analog computation via wave
interference. **Miller's own stated position: "This is a theory. We aim to test it by looking for
signatures of analog computation in brain wave patterns."** The original PDF tagged this [E]
(empirical) — that is wrong; the paper's own authors call it untested theory. Corrected to [HYP].

**EILT mapping [A]:** if this theory holds, it gives Wetware Polycomputing's GPU/GUI split a
candidate physical substrate — the wave-interference "ocean" as the wide-parallel posterior layer,
ephaptic routing as the mechanism connecting it to serial, narrow readout. Worth tracking as the
Miller lab's own follow-up work (testing for analog-computation signatures) publishes.

## 5. Anesthesia disrupts wave timing, not location — [EST], the strongest-sourced claim in the
whole set (corrected upward from an earlier session's premature skepticism)

Three independent, real, well-powered papers converge:
- Bardon, Miller et al., *Cell Reports* — ketamine and dexmedetomidine both cause **phase
  misalignment within a hemisphere** and **increased phase alignment across hemispheres** in
  primate PFC — a specific, testable, replicated signature, not "generic desynchronization."
- A companion 2026 *Cell Reports* paper — propofol, ketamine, and dexmedetomidine (three different
  molecular mechanisms: GABA agonism, NMDA antagonism, alpha-2 agonism) all produce the **same
  cortical dynamic-stability signature**, quantified via DeLASE, with real effect sizes and
  multiple-subject stats (p<0.001 in several comparisons).
- *Cell Reports Medicine* — human EEG (31 surgical patients): parietal-occipital-subcortical
  **alpha-band connectivity collapse** marks the actual transition to unconsciousness under
  propofol, replicated in a second 46-patient sedation cohort.

**EILT mapping [A]:** consciousness as rhythm/coordination rather than location is a strongly
supported empirical pattern independent of any theoretical framework we hold; it is compatible
with (not proof of) the internal-filter hypothesis. The honest claim: disruption of timing, not
location, correlates with loss of consciousness across three unrelated drug mechanisms and three
independent labs/methods. That is real, replicated, citable — treat as [EST] canon-grade support
material, distinct in tier from the [HYP] analog-computation theory above it.
