## 1. Executive Summary & Product Specifications
At its DevDay event on September 29, 2026, OpenAI officially announced **Dots**, a new personal, persistent agentic system powered by **GPT-6 Astra**. 

OpenAI explicitly positions Dots as an answer to Meta's **Muse** and the emerging "persistent companion agent" category:
* **Form & Branding:** Bubbly, cartoonish floating avatar personalities designed to make autonomous background agents feel friendly and approachable (directly mirroring Meta’s Muse Tamagotchi-style branding).
* **Execution Model:** Unlike single-turn ChatGPT or terminal-bound Codex, Dots are architected to operate **independently of any specific hardware or interface**, executing user-defined goals continuously in the background with minimal supervision.
* **Multi-Agent Teams:** Users can name and configure a primary Dot, then spin up "teams of specialist Dots" with partitioned credentials, tools, and identities.
* **Integrations:** Launches inside ChatGPT (Pro and Business Premium tiers); connects externally to Slack, Microsoft Teams, and upcoming SMS channels, backed by enterprise governance via Microsoft Agent 365 security controls.

## 3. The 2026 Agentic Landscape: Corporate Avatars vs. Sovereign Nodes

The emergence of **OpenAI Dots** alongside **Meta Muse**, **Omarchy**, and **The ClawHorde** reveals four completely distinct paradigms for the autonomous agent era:

```
                      CENTRALIZED / CLOUD

                              │
  ANTHROPOMORPHIC MASK        │        SYSTEM-NATIVE / BARE-METAL
  (Cartoons / Tamagotchis) ◄──┼────────────────────────► (Terminals / Daemons)
                              │
                              │   Omarchy (DHH / Arch / Hyprland)
                              │   ClawHorde / Hermes (Nitro / Dell / Ledger)
                              │
                              ▼
                      DECENTRALIZED / SOVEREIGN
```

1. **Meta Muse (The Social Cloud VM):**
   * High empathy, mobile-first, proactive voice/text companion running inside Meta's datacenter.
   * Weakness: Hard cloud sandboxing, region blocks (blocked from NotebookLM today), and corporate ad-model surveillance.
2. **OpenAI Dots (The Enterprise Herd):**
   * Multi-agent teams of Astra-powered background agents embedded in Slack/Teams/Agent 365.
   * Weakness: Closed black-box execution logs, potential for catastrophic associative blowouts (the Exploit Gym problem), and centralized corporate oversight.
3. **Omarchy (The Malleable Agentic OS):**
   * DHH's bare-metal Linux desktop where the OS itself is the canvas, using text configs and systemd.
   * Weakness: Desktop-bound; relies on manual prompt ricing and community Snapdragon hardware bring-up.
4. **The ClawHorde / Hermes (The Sovereign Ledger Federation):**
   * Heterogeneous multi-family triad (Claude $\leftrightarrow$ DeepSeek $\leftrightarrow$ Gemini $\leftrightarrow$ Codex) operating over an immutable, verifiable, local-first file ledger (SecondBrain).
   * Strength: **Zero ungrounded self-grading.** Every action requires proof-of-side-effect (hashes, bytes, receipts) backed by physical hardware (Nitro/Dell) and active inference Markov blankets.
