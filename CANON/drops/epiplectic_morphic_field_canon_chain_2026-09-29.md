## 7. Two-level epiplexity — and the answer to the bloat objection

**Gene:** *"local Markov epiplexity produced by ledger commits and universal applied epiplexity of how close it is to the ideal. That way the universe iterates on itself."*

```
local:      commits within blanket B → learnable structure in that run
universal:  deviation from ideal → learnable structure ACROSS runs
iteration:  the residual drives the next commit
```

**ANSWERS THE AUDIO'S CRITIQUE** (*"you cannot run an infinite, append-only ledger on finite metal without burning the substrate to the ground"* / *"immutability without the ability to forget or structurally decouple risks trapping the agent in a pathological, unrecoverable rut"*):
→ **Local epiplexity is MARKOV-BOUNDED. The locality IS the bound** — not a pruning policy bolted on, but the architecture's own ceiling. The blanket provides the decoupling.

**Precision required:** epiplexity is a property of a **distribution**, not a single sample. So "local Markov epiplexity produced by ledger commits" = the learnable structure in the **commit sequence**, bounded by the blanket. One commit is a draw.

**Coherent reading of the universal term:** "closeness to the ideal" is a *distance*; epiplexity is *learnable structure*. Coherent only as **epiplexity OF THE DEVIATION** — i.e. **the deviation is structured, not noise. The error has a shape, and the shape of the error is what you learn from.**

**Falsifier:** **NULL — if the deviation is i.i.d. noise, epiplexity(deviation) = 0 and there is nothing to learn.** Rejected on our own data: we classify failures into named classes with recurring signatures.

**Operational consequence:** the ledger doesn't *record* the learning — **the ledger commits are what GENERATE the local epiplexity.** Reasoning is external to the weights because the commit sequence holds the learnable structure of how capability missed.
